AI audit vs manual audit: what each one is for

An AI audit and a manual audit do different jobs. An AI audit reviews a whole codebase and every later change, and QuillShield also tries to prove its findings with proof of concept exploits. A manual audit adds human judgment on design, economics and intent. QuillShield does not replace a manual audit. It reviews the changes between audits.

QuillAudits has audited 1,500+ protocols since 2018 and also makes QuillShield, so we sell both sides of this comparison. Our advice is to use both, in a set order, and to know what each one cannot do.

Do you still need a manual audit if you run an AI audit?

Yes, if your contracts will hold user funds. An AI audit finds many known bug types and can run on every change, but it misses some bugs and does not judge whether a design is sound. A manual audit does that for one fixed commit. Run the AI audit first, then on every pull request after the manual audit.

What does an AI audit do well?

  • It reads everything in scope, then every change. An AI audit goes through all the files you select, and a pull request check then reviews each change against that audit. No team can book auditors for every merge.
  • It finds known bug types. In our own run on 8 July 2026, the QuillShield alpha found 98 of the 117 known vulnerabilities in EVMbench (83.8%, self-reported) across 40 audited projects. The best single model in the original EVMbench paper found 45.6%. That compares a multi-agent system with one model working alone, and it is not a ranking of tools. Our EVMbench results has the detail.
  • It shows its evidence. Each QuillShield finding comes with the exact lines, the impact and a recommended fix. On a full audit it also carries a proof of concept result.
  • It returns in hours. The demo audit on the home page reported 5 findings, 3 of them Critical, with 5 of 5 proofs of concept passed, in 2h 7m. Larger codebases take longer.
  • Most reviewed findings held up. During the private beta, 90% of the findings QuillAudits auditors reviewed on client Solidity code were valid.

What does a manual audit do that AI does not?

  • It judges the design. Auditors ask whether the mechanism does what the team intends, whether the incentives hold when markets move, and which roles and oracles the protocol has to trust. QuillShield can check code against the documents you attach. It does not decide whether the plan in those documents is a good one.
  • It puts more than one person on the code. A manual audit by QuillAudits means two line-by-line passes over the code, then a lead auditor's own review.
  • It can look outside the repository. Deployment settings, key management and off-chain services are part of the attack surface, and a manual engagement can bring them into scope. An AI audit sees the files you give it.
  • It can catch what the machine missed. In our own EVMbench run the alpha missed 19 of the 117 known vulnerabilities. Some AI findings are also invalid, and proofs of concept do not pass for every finding.
  • It covers code QuillShield cannot take yet. QuillShield supports Solidity for Foundry projects and nothing else today. QuillAudits lists manual audits for chains beyond the EVM, such as Solana and NEAR.
  • It puts a named firm behind the review. Exchanges and investors often ask for a report from a firm they know before a listing or a funding round.

Manual audits have limits of their own. A report describes one commit. Code merged after it has not been reviewed by anyone, and booking a new audit for every change is not practical. Reviewing those changes is the job QuillShield was built for.

Which should you use, and when?

  1. While you build, run a full AI smart contract audit once the code is stable enough to scope, and fix what it finds.
  2. Before the manual audit, run it again on the frozen commit and give the auditors the report as a starting point. Run your first audit covers the steps.
  3. Before launch or a major upgrade, get the manual audit.
  4. After it, turn on pull request checks. Each change is checked against the last full audit, and the check fails on a High or Critical finding unless you set another threshold.
  5. When a change is large, run a new full audit. If the design itself changed, go back to the auditors.

How do you escalate an AI finding to an auditor?

A completed QuillShield audit offers two requests, described in the docs on expert review. One asks a QuillAudits auditor to verify specific findings. The other asks for a manual audit led by auditors. Both are forms that go to the QuillAudits team. Neither is a self-serve purchase and the docs give no turnaround time, so ask about timing when you send one.

Common questions

Does QuillShield replace a manual audit?

No. QuillShield is an AI smart contract audit that runs between manual audits. It reviews every change, and you can request a manual audit from QuillAudits.

Should I run an AI audit before a manual audit?

Yes. Run the AI audit first and fix what it finds, so the auditors can spend their time on design, economics and intent. You can give them the AI report as a starting point.

Can a human auditor check an AI finding?

Yes. On a completed QuillShield audit you can ask a QuillAudits auditor to verify specific findings. The request is a form that goes to the QuillAudits team. It is not a self-serve purchase.
